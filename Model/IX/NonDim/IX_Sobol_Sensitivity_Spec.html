Implementation Spec — Sobol Sensitivity Analysis of the Non-Dim IX Column

Model Non-dimensional ion-exchange column (forward solver per IX_Column_Diffrax_Spec.md). This spec defines the factors, bounds, and metrics for the Sobol sweep and uses the existing forward model — it does not re-implement the solver.
Goal Global (variance-based) Sobol sensitivity analysis of column performance w.r.t. the dimensionless groups. Center of gravity: §3 — defensible, realistic bounds.

1. Objective

Quantify how much each dimensionless group drives the column's performance, using first-order ($S_i$) and total-order ($S_{T_i}$) Sobol indices. Identify which groups dominate, which interact, and which are negligible (expected: $\omega$). This screens the design space before any optimization.

2. Forward model (the function being sampled)

The non-dim system, with the isotherm written in the dimensionless feed-favorability $\beta$:

$$ \begin{aligned} \frac{\partial A^*}{\partial t^*} &= -\frac{\partial A^*}{\partial x^*} - \Lambda\,\frac{dn^*}{dt^*},\qquad \frac{\partial T^*}{\partial t^*} = -\frac{\partial T^*}{\partial x^*} + \Lambda\,\frac{dn^*}{dt^*}\\[4pt] \frac{dn^*}{dt^*} &= Da\,(n^*_{eq}-n^*),\qquad n^*_{eq}=\frac{(1+\beta)\,A^*}{h + \beta A^*},\\[4pt] h &= \frac{H^*}{H^*_{in}},\qquad H^*=\frac{T^*+\sqrt{(T^*)^2+4\omega}}{2}. \end{aligned} $$

Here $\beta \equiv K^*/H^*_{in}=K^*A_{in}/[H^+]_{in}$ is the dimensionless Langmuir number at feed, and $h=H^*/H^*_{in}$ is the local proton level relative to the (fixed) feed reference $H^*_{in}$. At feed ($A^*=1$, $h=1$), $n^*_{eq}=1$ by construction; $\beta\!\ll\!1$ unfavorable/linear, $\beta\!\gg\!1$ rectangular. Raising $h$ (acidifying during elution) collapses $n^*_{eq}\to0$ — the desorption limit.

The forward model exposes qois(params) → dict[str, float] (one cycle → the scalar metrics of §4), pure JAX / eqx.filter_jit-able so the sweep can jax.vmap-batch it.

2.1 Mapping sampled groups → model parameters

  • $\Lambda$, $Da$, $\beta$, $\omega$ enter the equations directly (no back-substitution — the isotherm is already in $\beta$).
  • Fix a nominal feed proton reference $H^*_{in}$ (a constant of the non-dimensionalization, e.g. from a representative favorable feed pH); then $h=H^*/H^*_{in}$ and the feed proton excess $T^*_{in,\text{load}}=H^*_{in}-\omega/H^*_{in}$.
  • Eluent strength (cycle analysis): the eluent inlet proton excess $\Pi_{el}\equiv T^*_{el}$ at the desorption-phase inlet.

Keep $H^*_{in}$, $A^*_{in}=1$, $\eta_{min}$, the eluate tail cutoff $A^*_{tail}$, grid $N$, and domain length fixed (documented constants), not sampled.

All ranges span several decades, so sample log-uniformly: bounds are given (and stored) as $\log_{10}$, exponentiated before entering the model.

4. Quantities of interest

A full load→desorb cycle. Load ends at breakthrough ($\eta<\eta_{min}$); desorption ends when the eluate falls below a tail threshold ($A^*_{out}

Primary objectives:

  • Productivity $\Pi_{\text{prod}} = \Lambda\,\dfrac{\Delta n^*}{t^*_{\text{cyc}}}$ — A recovered per bed volume per cycle time (non-dimensionalized by feed delivery rate $u_sA_{in}/L$). Primary target. Scales with $\Lambda$; the shape/kinetics signal lives in $\Delta n^*/t^*_{\text{cyc}}$.
  • Acid usage $\lambda_{\text{acid}} = \dfrac{\Pi_{el}\,t^*_{des}}{\Lambda\,\Delta n^*}$ — molar acid:Li ratio fed during desorption. Floor $=1$ (1 H⁺ per A⁺ exchanged); lower better. Use $1/\lambda_{\text{acid}}$ for an efficiency $\in(0,1]$. Scales as $1/\Lambda$ — opposes productivity.
  • Recovery $R = \dfrac{\Delta n^*}{\langle n^*\rangle_{\text{load}}}$ — fraction of loaded A eluted ($\in[0,1]$).
  • Eluate concentration factor $CF = \langle A^*_{out}\rangle_{des}$ (mean) and $CF_{\text{peak}}=\max A^*_{out}$ — product enrichment over feed.

Diagnostics (computed, secondary): bed utilization $\varphi = \langle n^*\rangle_{\text{load}}/n^*_{eq}(\text{feed})$; MTZ width ($x^*$ span where $0.05

All QoIs dimensionless; each gets its own Sobol decomposition. With the eluate-tail stop, $R$, $\lambda_{\text{acid}}$, $CF$, and $t^*_{des}$ are all free outputs ($A^*_{tail}$ is a fixed control). These are the keys returned by qois(params).

Trade-off built into the set: $\Pi_{\text{prod}}\!\propto\!\Lambda$ while $\lambda_{\text{acid}}\!\propto\!1/\Lambda$ — the group that raises productivity worsens acid economy. The sweep should surface where $Da$, $\beta$, $\Pi_{el}$ tilt this balance.

5. Pitfalls / interpretation

  • $\Lambda$ dominance is built into several QoIs. $t^*_{bt}\approx 1+\Lambda\,\varphi$, $\Pi_{\text{prod}}\!\propto\!\Lambda$, $\lambda_{\text{acid}}\!\propto\!1/\Lambda$ — so $\Lambda$'s total index is large on all three by construction. To expose kinetics/shape drivers, also analyze the $\Lambda$-removed parts: $\Delta n^*/t^*_{\text{cyc}}$, $\Pi_{el}t^*_{des}/\Delta n^*$, and $\varphi$ / MTZ width (these isolate $Da$, $\beta$, $\Pi_{el}$). Analyzing $\log$ of the strongly-scaled QoIs tames the range.
  • Log vs linear sampling changes the indices. They're conditional on the input distribution; log-uniform is right for decade-spanning groups — state it.
  • Convergence: re-run at $2N$, confirm $S_i$, $S_{T_i}$ move within bootstrap CIs. Report CIs.
  • Numerical diffusion floor: upwind adds dispersion $\sim u\,\Delta x/2$; at high $Da$ the front is sharper than the grid, so MTZ-width sensitivity can saturate on $N_{grid}$ not $Da$. Set $N_{grid}$ from a convergence check at the highest-$Da$ corner.
  • Cost / robustness: each evaluation is a PDE solve, not algebra. Stiff corners (large $\Lambda$ with large $Da$) may hit max_steps/NaN — NaN-flag failed solves rather than imputing. $t^*_{bt}\sim\Lambda$, so high-$\Lambda$ samples integrate over long $t^*$; cap load-phase $t^*_{max}$ and treat non-breakthrough as censored.

6. Deliverable

Code only. A runnable implementation of: the forward-model wrapper exposing qois(params), the metrics of §4, and the Sobol problem definition (factors + $\log_{10}$ bounds of §3) wired into the Sobol harness. No result artifacts, runs, plots, or reports — execution and analysis are done separately.

7. Out of scope

Optimization, physical-parameter (dimensional) sampling, dispersion/film-resistance terms, SEC/pumping energy (needs a pressure-drop term this model omits), Morris/FAST alternatives (Sobol only for v1).

Bound ranges grounded in DLE literature: Sunresin DLE overview; γ-MnO₂ geothermal Li (Tuzla); titanium-based Li-ion sieve review; Mn–Ti mixed ion sieves; fixed-bed IX non-equilibrium mass-transfer modeling.
