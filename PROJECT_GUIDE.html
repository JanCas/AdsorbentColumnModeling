1. The big picture

The project models a packed bed of sorbent particles through which a feed solution flows. The target species (e.g. lithium) is captured during an adsorption phase and then recovered during a desorption (elution) phase. Two physically distinct capture mechanisms are modeled:

  • AlLDH a lithium/aluminium layered‑double‑hydroxide adsorbent with pseudo‑second‑order uptake kinetics and a Langmuir isotherm.
  • IX an ion‑exchange resin where lithium uptake releases protons, so the model carries explicit acid/base (pH) chemistry.

Each model exists in two forms: a dimensional version in SI units (used for engineering optimization) and a non‑dimensional version (used for sensitivity analysis, so results are mechanism‑agnostic and comparable across the two models). Everything is written in JAX and integrated with the diffrax ODE solver, which makes the forward model fast, vectorizable, and differentiable.

2. The physical system

Picture a vertical cylindrical column packed with porous sorbent grains. Liquid flows through the void space (porosity \(\varepsilon\)) at interstitial velocity \(u_{int}=u_{super}/\varepsilon\). As solute‑laden feed moves through, solute transfers from liquid onto the solid until the solid saturates. The concentration "front" travels down the bed; when it reaches the outlet (breakthrough) the adsorption step is stopped. The flow is then switched to a stripping eluent that pulls the captured species back off the solid and concentrates it in a small eluate volume.

3. The shared modeling framework

Both models share the same skeleton: a 1‑D advection equation for the mobile (liquid) phase coupled to a lumped kinetic law for the stationary (solid) phase, with an equilibrium isotherm setting the driving force. Axial dispersion is neglected; transport is pure plug‑flow advection plus mass transfer to the solid.

The three ingredients

IngredientRoleForm used here
Advectioncarries solute down the bedfirst‑order upwind (backward) finite difference
Isotherm \(n_{eq}(C)\)equilibrium solid loading at a given liquid concentrationLangmuir (AlLDH & IX); pluggable Temkin/Sips in the dimensional AlLDH
LDF kineticsrate of approach to equilibrium (linear driving force)\(\dot n = k\,(n_{eq}-n)\) — or pseudo‑2nd‑order in the dimensional AlLDH

The liquid mass balance says: what accumulates in the fluid = what advects in − what the solid takes up. In dimensional form, per unit bed volume,

$$ \frac{\partial C}{\partial t} \;=\; -\,u_{int}\frac{\partial C}{\partial x}\;-\;\underbrace{\frac{1-\varepsilon}{\varepsilon}\,\rho_p}_{\text{solid/liquid volume}}\frac{\partial n}{\partial t}, \qquad \frac{\partial n}{\partial t}=k\,\big(n_{eq}(C)-n\big). $$
Reading the coupling. When the solid grabs solute (\(\dot n>0\)), the last term is a sink on the fluid. The dimensionless capacity ratio that emerges from this term, \(\Lambda\), is the single most important group in the whole project — it sets how much solute the bed can hold relative to what the fluid delivers.

Boundary & initial conditions — the common pattern

Every variant follows the same scheme, so it is worth stating once. The bed occupies \(x\in[0,L]\) (or \(\zeta\in[0,1]\) non‑dimensional), and a cycle is two phases solved back‑to‑back:

  • Inlet (\(x=0\)): one Dirichlet condition, applied through a ghost cell just upstream of the first node — the concentration entering the bed is fixed to the feed (loading) or to the stripping fluid (desorption).
  • Outlet (\(x=L\)): none imposed. Because transport is pure advection (no axial dispersion), the upwind scheme just carries material out the end. A "free"/outflow outlet is the correct and complete boundary treatment — adding an outlet condition would over‑specify the problem.
  • Initial condition: adsorption starts from an essentially empty bed (carrying only a small residual loading left by the previous strip); desorption starts from the fully loaded profile handed over at the end of adsorption, with the inlet switched off.

4. Model A — AlLDH adsorption AlLDH

AlLDH (aluminium layered double hydroxide) selectively adsorbs Li⁺. Capture is a surface process described by a Langmuir isotherm; the uptake rate follows pseudo‑second‑order (PSO) kinetics in the dimensional model.

4.1 Dimensional form dimensional

Source: Model/AlLDH/diffrax_column_model.py · parameters from utils/Dataclasses.py

$$ \frac{\partial C}{\partial t} = -u_{int}\frac{\partial C}{\partial x} - \frac{1-\varepsilon}{\varepsilon}\rho_p\frac{\partial n}{\partial t}, \qquad \frac{\partial n}{\partial t} = k_s\,(n_{eq}-n)\,\lvert n_{eq}-n\rvert .$$

The kinetic term is pseudo‑second‑order: the rate is proportional to the square of the distance from equilibrium (the \(|n_{eq}-n|\) keeps the sign correct for both uptake and release). The isotherm \(n_{eq}(C)\) is supplied as a callable, so the same column code runs with a Temkin or Sips isotherm fitted to literature data.

4.2 Non‑dimensional form non‑dimensional

Source: Model/AlLDH/diffrax_non_dim_qmax.py · driven by the Sobol harness

5. Model B — Ion exchange (IX) IX

In an ion‑exchange resin, capturing one Li⁺ releases one H⁺ from the exchange site. The liquid therefore acidifies as it loads, and that pH change feeds back on the isotherm. The IX model's defining feature is that it tracks proton chemistry explicitly — it is a three‑field model (\(A\): the cation, \(T\): a proton‑excess variable, \(n\): solid loading) instead of two.

5.1 Dimensional form dimensional

Source: Model/IX/dim/ix_model.py

$$ \frac{\partial A}{\partial t} = -\frac{u_s}{\varepsilon}\frac{\partial A}{\partial x} - \frac{1-\varepsilon}{\varepsilon}\rho_p\,\dot n, \qquad \frac{\partial T}{\partial t} = -\frac{u_s}{\varepsilon}\frac{\partial T}{\partial x} + \frac{1-\varepsilon}{\varepsilon}\rho_p\,\dot n .$$

The two fluid balances are mirror images: every mole of \(A\) that leaves the liquid puts a proton back (anti‑symmetric coupling), so \(A+T\) is purely advected — a clean mass‑balance check. The free proton concentration is recovered from the proton‑excess variable \(T\) by the water self‑ionization closure (the positive root of \([H^+]^2-T[H^+]-K_w=0\)):

$$ [H^+] = \tfrac12\Big(T+\sqrt{T^2+4K_w}\Big), \qquad n_{eq}=Q_{sites}\,\frac{K^\!*\,A}{[H^+]+K^\!*\,A}, \qquad \dot n = k\,(n_{eq}-n).$$

5.2 Non‑dimensional form non‑dimensional

Source: Model/IX/NonDim/ix_nondim_qmax.py · driven by the Sobol harness

With \(A^*=A/A_{in}\), \(n^*=q/q_{max}\), \(\zeta=x/L\), \(\tau=t\,u_{int}/L\) and \(H^*=[H^+]/A_{in}\):

$$ \frac{\partial A^*}{\partial\tau}=-\frac{\partial A^*}{\partial\zeta}-\Lambda\,\dot n^*,\qquad \frac{\partial T^*}{\partial\tau}=-\frac{\partial T^*}{\partial\zeta}+\Lambda\,\dot n^*,$$ $$ \dot n^* = Da\,(n^*_{eq}-n^*),\qquad n^*_{eq}=\frac{K^\!*\,A^*}{H^*+K^\!*\,A^*},\qquad H^*=\tfrac12\Big(T^*+\sqrt{T^{*2}+4\omega}\Big).$$

It is the same advection–LDF skeleton as AlLDH (compare the equations above), with two extra groups for the proton chemistry:

GroupDefinition / role
\(\Lambda\)\(\frac{1-\varepsilon}{\varepsilon}\rho_p\,q_{max}/A_{ref}\) — capacity ratio (same role as AlLDH)
\(Da\)\(kL/u_{int}\) — Damköhler (same role as AlLDH)
\(K^\!*\)bare dimensionless mass‑action constant in the isotherm
\(\omega\)\(K_w/A_{ref}^2\) — dimensionless water‑floor term in the \(H^*\) closure
\(H^*_{in,ads},\,H^*_{in,des}\)inlet proton level (feed pH vs. strip pH); set the inlet \(T^*=H^*-\omega/H^*\)
The buffer axis \(B\). The Sobol harness found the QoIs depend only on the ratio \(B=\omega/H^*_{in,ads}=[\mathrm{OH^-}]_{in}/A_{in}\) (feed basicity), not on \(\omega\) and \(H^*_{in,ads}\) separately. So a single sampled log10_buffer axis replaces both: \(\omega\) is fixed at a reference and \(H^*_{in,ads}=\omega/B\) is derived. The bed only loads when \(B>1-C^*_{th,ads}\).

The inlet \(T^*\) is set from the desired inlet proton level through the exact inverse \(T^*=H^*-\omega/H^*\), so that \(H^*\) at the inlet equals the feed pH (load) or strip pH (desorb).

6. Why non‑dimensionalize?

The dimensional models have 6–12 dimensional knobs each (lengths, velocities, densities, rate constants). Many combinations are physically equivalent — doubling the column length and the velocity together changes nothing. Non‑dimensionalization collapses those knobs into a handful of independent groups (\(\Lambda, Da, \theta/K^*, \ldots\)) that fully determine the dimensionless solution. This is what lets the sensitivity study answer "which physics matters?" in a way that transfers between the two models: both reduce to the same \(\Lambda\)–\(Da\) advection/kinetics core, so their Sobol indices are directly comparable.

The forward model is wrapped in @eqx.filter_jit (JAX just‑in‑time compilation). A hard rule in this codebase: no Python print/logging inside a JIT‑compiled body — it would fire once at trace time, not per run. All runtime logging lives in the orchestration layer (the Sobol driver / optimizer).

8. Sensitivity analysis (Sobol) non‑dimensional

Goal: quantify how much each dimensionless input drives each performance metric, including interactions. The method is variance‑based (Sobol) global sensitivity analysis via SALib. For each output, Sobol decomposes its variance over the input box into contributions from each input and their combinations:

  • \(S_1\) (first‑order): fraction of output variance explained by an input alone.
  • \(S_T\) (total‑order): an input's contribution including all its interactions. \(S_T-S_1\) is its interaction load.
  • \(S_2\) (second‑order, optional): variance from a specific pair of inputs.

Architecture: driver + adapters

The design cleanly separates the generic from the specific. Sensitivity/sobol_driver.py owns the sampling loop, SALib analysis, CSV writing, and plotting. A small adapter (Sensitivity/adapters/*_qmax.py) is a frozen SobolModel dataclass that declares, for one study: the parameter names, their bounds and distributions, a run(vec)→{metric: value} closure that calls the forward model, and the named outputs. To study a new model you write one adapter.

ModelSampled inputs (typical "full" study)Bounds note
AlLDHlog10_Lambda, log10_Da, log10_theta, C_thresh_ads, C_thresh_desseveral presets (legacy, alldh_log, ix) so AlLDH and IX can be compared on matched ranges

The studies produce the metrics in the glossary (adsorption/desorption times, bed utilization, recovered amount, productivity, wash/release split, and outlet pH for IX). Inputs are sampled uniformly, usually in \(\log_{10}\) so that \(\Lambda, Da, K^*\) span orders of magnitude evenly.

9. Optimization (NSGA‑II) dimensional

Source: Model/AlLDH/multi_optim.py (uses the dimensional AlLDH column)

Goal: find column designs that are simultaneously cheap to run and productive. This is a two‑objective problem with no single best answer — instead there is a Pareto front of non‑dominated trade‑offs, found with the genetic algorithm NSGA‑II (via pymoo).

Decide (5 design variables)

  • L — column length [m]
  • u_super — superficial velocity [m/s]
  • des_threshold — desorption stop level
  • k_s — kinetic rate constant [1/s]
  • epsilon — bed porosity

Optimize (2 objectives)

  • minimize SEC — specific energy consumption [J/mol], pumping energy ÷ Li recovered
  • maximize productivity [mol·m⁻²·s⁻¹], Li recovered ÷ cycle time ÷ length

Pumping energy uses the Ergun equation for pressure drop through the packed bed; infeasible individuals (solver failure, no net recovery) are rejected with \(\infty\).

11. How to run it

Install

# Python 3.13+; see requirements.txt
pip install -r requirements.txt
# key deps: jax, diffrax, equinox, SALib, pymoo, pandas, matplotlib, tqdm

Sensitivity sweep (both models, "joint" runner)

# Runs the AlLDH + IX non-dim q_max models through one Sobol study each.
python -m Sensitivity.run_joint_qmax --output-dir Results/Sensitivity/my_run \
       --N 2048 --ix-scope full --bounds ix
# add --second-order for S2 indices; --data-plots for scatter PNG/SVGs;
# --log10-da-range / --log10-lambda-range ... to trim the sampling box.

The driver also exposes run_sobol(model, N=…) directly if you build a single adapter via get_model() / get_full_model() and want one model only.

Optimization (dimensional AlLDH)

python Model/AlLDH/multi_optim.py --brine_concentration 50 \
       --loss-fraction 0.01 --output_dir Results/Optimization/my_opt
# writes pareto_front_<loss>.csv and a Pareto plot.
Set the log level via the environment, e.g. LOG_LEVEL=DEBUG python -m Sensitivity.run_joint_qmax …. JAX is forced onto CPU and float64 inside the runners.

One thing to know about the cleanup. The repo was trimmed to the q_max‑normalized non‑dimensional models only (an older feed‑equilibrium‑normalized variant and a standalone Sobol script were removed). The single sensitivity entry point is Sensitivity.run_joint_qmax; there is no separate single‑model runner anymore. Comments in some files still reference the deleted diffrax_non_dim.py/ix_nondim.py by name — those are historical breadcrumbs, not live imports.

★ marks the files most worth reading first. The two non‑dimensional model files are each ~260–480 lines and are heavily commented — start there, then read the matching adapter to see exactly which groups are swept and over what ranges.
